# Description

libft is a custom static library made out of collection of C functions inspired from the C standard library.

# Instructions

first we need to execute Makefile file using the command make to compile all the files and create object files .o and libft.a.

the command make fclean to delete the object files and libft.a.

the command make clean to delete the object files.

the command make re to rebuild the library agian after delteing it.

the command cc -Wall -Wextra -Werror main.c libft.a to test the functions in a main function .
